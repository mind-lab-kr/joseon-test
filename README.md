# 🏯 조선시대에 태어났다면?

10가지 질문으로 알아보는 "나의 조선시대 신분과 삶" 심리테스트 웹사이트입니다.

## 1. 현재 완성된 기능
- 조선시대 테스트 소개 랜딩 페이지 (`index.html`)
  - 맞춤 제작된 썸네일 배너 이미지 노출
  - 테스트 카드 1개만 중앙에 배치되는 반응형 레이아웃
- 10문항 심리테스트 (`joseon-test.html` / `js/joseon-test.js`)
  - 6가지 결과 유형: 양반(선비), 장수, 거상, 화공, 의병, 예인
  - 진행 상황 표시(progress bar), 이전/다음 문항 이동
- **2단계 결과 공개 구조**
  1. 기본 결과 화면: 결과 유형 요약 + 쿠팡 광고 안내(배지·고지문구·상품 카드·버튼) 통합 표시
  2. "쿠팡 링크 클릭하기" 버튼 클릭 → 새 창으로 쿠팡 상품 페이지가 열림 → 그 창을 닫거나(또는 원래 창으로 포커스가 돌아오면) 자동으로 심층 결과 화면으로 전환
  - 쿠팡 파트너스 링크 3개를 내부적으로 순차 순환(품절/오류 대비), 화면에는 순환 관련 표시를 노출하지 않음
  - "📢 광고" 배지 및 "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." 고지문구 표기
- 결과 공유 기능: URL 쿼리 파라미터(`?result=유형코드`)로 특정 결과 화면 직접 진입 가능
- SNS/블로그 미리보기용 `og:title`, `og:description`, `og:image` 메타태그 설정

## 2. 기능 진입 경로 (URI)
| 경로 | 설명 |
|---|---|
| `index.html` | 메인 소개 페이지 (테스트 시작 진입점) |
| `joseon-test.html` | 테스트 진행 및 결과 화면 |
| `joseon-test.html?result=yangban` 등 | 특정 결과 유형으로 바로 진입 (yangban, general, merchant, artist, righteous, entertainer) |

## 3. 아직 구현되지 않은 기능 / 참고 사항
- 실제 쿠팡 상품 품절·오류 여부를 실시간으로 감지하는 기능은 정적 사이트(CORS 제약)에서는 구현이 불가능합니다. 대신 새 창 닫힘/포커스 복귀를 감지해 다음 단계로 넘어가는 방식으로 체감 흐름을 구현했습니다.
- 결과 데이터/방문 통계 등을 저장하는 백엔드/DB 연동은 없습니다(순수 클라이언트 사이드 정적 페이지).

## 4. 다음 개발 추천 사항
- 결과 화면에 카카오톡/문자 공유 버튼 추가
- 결과별 SNS 공유 시 결과 유형에 맞는 개별 og:image 적용
- 방문자 통계가 필요하다면 Google Analytics 등 클라이언트 스크립트 연동 검토

## 5. 프로젝트 개요
- **이름**: 조선시대에 태어났다면?
- **목표**: 재미로 즐기는 심리테스트를 통해 방문자에게 즐거움을 주고, 쿠팡 파트너스 링크를 통한 수익화를 병행
- **주요 기능**: 10문항 심리테스트, 6가지 결과 유형, 쿠팡 파트너스 연동, 결과 공유 링크

## 6. 배포 URL
- Genspark 배포(Publish) 링크: `https://obydbrpp.gensparkspace.com`

## 7. 데이터 모델 / 저장 방식
- 별도의 DB나 테이블 API를 사용하지 않는 순수 정적 웹사이트입니다.
- 테스트 문항, 결과 유형, 쿠팡 링크 등 모든 데이터는 `js/joseon-test.js` 내 JavaScript 객체(`QUESTIONS`, `RESULT_TYPES`, `COUPANG_LINKS`)로 관리됩니다.
